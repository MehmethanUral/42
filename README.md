# 42 İstanbul

This repository brings together the projects I complete as a student at
[42 İstanbul](https://www.42istanbul.com.tr/), part of the global
[42 Network](https://www.42network.org/).

## Why this repository?

At 42 there are no teachers and no lectures. Students learn by building
projects, solving problems on their own and evaluating each other's work.
Most projects are written in C and focus on the fundamentals: memory,
pointers, system calls, algorithms and writing clean, well-structured code
under a strict coding standard (the *Norm*).

Each project is submitted to the school's own Git server for peer evaluation.
This repository keeps a copy of them in one place, so I can:

- track my progress through the 42 curriculum,
- keep my work as a portfolio,
- come back to earlier projects when later ones build on them.

Every project lives in its own folder and has its own `README.md` explaining
what it does and how it works.

## Note

If you are a 42 student, feel free to use these projects to understand the
ideas, but write your own code. That is the whole point of 42.
